# PIIUA — Веб-сервіс псевдонімізації персональних даних для української мови 🇺🇦

[![Release](https://img.shields.io/badge/Release-v1.0.16--beta-orange.svg)](https://github.com/KozlitinI/PIIUA/releases/tag/v1.0.16-beta)
[![Python Version](https://img.shields.io/badge/python-3.10%20%7C%203.11%20%7C%203.12-blue.svg)](https://www.python.org)
[![FastAPI](https://img.shields.io/badge/FastAPI-0.100%2B-009688.svg)](https://fastapi.tiangolo.com)
[![spaCy](https://img.shields.io/badge/spaCy-3.8-09A3D5.svg)](https://spacy.io)
[![License](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](LICENSE)
[![User Manual](https://img.shields.io/badge/User%20Manual-MANUAL.md-green.svg)](MANUAL.md)
[![Documentation Markdown](https://img.shields.io/badge/Documentation-Markdown-blue.svg)](THESIS.md)

**PIIUA** — це відкритий (Open Source) локальний веб-сервіс для автоматичного виявлення, псевдонімізації та де-псевдонімізації (відновлення) персональних даних (PII) в українських юридичних, судових та офіційних документах.

Сервіс працює повністю локально на вашому комп'ютері без передачі даних у хмару, що забезпечує максимальну конфіденційність та відповідність вимогам законодавства про захист персональних даних.

> 📖 **Детальна інструкція користувача** доступна у файлі **[MANUAL.md](MANUAL.md)**.  
> 📄 Опис системи, її архітектури та алгоритмів доступний у документі **[THESIS.md](THESIS.md)**.

## 🌟 Основні можливості

- **Виявлення українських PII сутностей:**
  - **ПІБ (Прізвище, Ім'я, По батькові):** Повна підтримка відмінювання, ініціалів та лематизації (повернення до називного відмінка).
  - **РНОКПП (ІПН):** Валідація за алгоритмом контрольної суми та дати народження.
  - **Паспорти:** Паспорти громадянина України (серія/номер та 9-значні ID-картки).
  - **IBAN:** Українські банківські рахунки.
  - **Телефони:** Українські номери у всіх популярних форматах.
  - **Номери судових справ:** Специфічні формати судових документів (наприклад, `757/12345/23-ц`).
  - **Адреси та Автомобільні номери:** Вулиці, міста та номери ТЗ.
  - **Назви організацій та компаній:** ТОВ, ПрАТ, Державні установи тощо.

- **Вибір мовних моделей spaCy:**
  - `uk_core_news_trf` *(Transformer, за замовчуванням)* — найвища точність розпізнавання контексту.
  - `uk_core_news_lg` *(Large)* — висока точність та швидка обробка.
  - `uk_core_news_sm` *(Small)* — легковагова модель.

- **Двостороння обробка (Псевдонімізація + Відновлення):**
  - Заміна PII на теги типу `<PERSON_1>`, `<RNTRC_1>`, `<IBAN_1>`.
  - Генерація карти відповідностей для зворотного відновлення оригіналу.

## 🚀 Встановлення та запуск на Windows

### Спосіб 1. Встановлення через готовий EXE-інсталятор (Рекомендовано) ⭐️

Найшвидший та найпростіший спосіб для користувачів Windows. Інсталятор містить автономну збірку програми з усіма компонентами, веб-сервером та українськими мовними моделями spaCy — **встановлювати Python, Git або вручну налаштовувати залежності не потрібно**.

1. **Завантажте інсталятор:**
   - 📥 [**PIIUA_Setup_v1.0.16b.exe**](https://github.com/KozlitinI/PIIUA/releases/download/v1.0.16-beta/PIIUA_Setup_v1.0.16b.exe) *(пряме посилання на завантаження)*
   - Або завантажте його зі сторінки офіційного релізу: **[GitHub Releases — v1.0.16-beta](https://github.com/KozlitinI/PIIUA/releases/tag/v1.0.16-beta)**.

2. **Запустіть процес інсталяції:**
   - Двічі клацніть завантажений файл `PIIUA_Setup_v1.0.16b.exe`.
   - > 💡 **Попередження Windows SmartScreen:** Якщо під час першого запуску з'явиться синє вікно *«Система Windows захистила ваш ПК»* (*Windows protected your PC*):
     > 1. Натисніть посилання **«Докладніше»** (*More info*).
     > 2. Натисніть кнопку **«Виконати у будь-якому разі»** (*Run anyway*).

3. **Слідуйте підказкам майстра встановлення:**
   - Оберіть мову інтерфейсу інсталятора (**Українська** або **English**).
   - За замовчуванням програма встановлюється в папку користувача і **не вимагає прав адміністратора**.
   - Позначте прапорець **«Створити ярлик на Робочому столі»** для швидкого доступу.
   - Натисніть **«Встановити»** та дочекайтеся завершення копіювання файлів.
   - На фінальному екрані залиште позначку **«Запустити PIIUA»** та натисніть **«Завершити»**.

4. **Запуск та робота з програмою:**
   - Надалі запускайте програму за допомогою створеного ярлика **PIIUA** на Робочому столі або через меню **«Пуск»**.
   - Відкриється вікно консолі локального сервера, і за декілька секунд у вашому браузері за замовчуванням автоматично відкриється веб-інтерфейс:  
     👉 **`http://127.0.0.1:8000`**
   - Для зупинки програми просто закрийте вікно консолі сервера або натисніть у ньому комбінацію клавіш `Ctrl+C`.
   - 📖 *Детальний покроковий посібник користувача з описом інтерфейсу, налаштувань та прикладів роботи з ШІ наведено у файлі **[MANUAL.md](MANUAL.md)**.*

### Спосіб 2. Запуск із вихідного коду через BAT-скрипти (за наявності Python)

Якщо ви бажаєте запустити сервіс безпосередньо з вихідного коду репозиторію:

#### Крок 1. Перевірка / Встановлення Python

Для роботи програми необхідний **Python версії 3.10, 3.11 або 3.12**.

1. Перевірте, чи встановлено Python, відкривши **Командний рядок (cmd)** та ввівши:
   ```cmd
   python --version
   ```
2. Якщо Python не встановлено:
   - **Спосіб А (Рекомендовано):** Завантажте **Python 3.11** з [офіційного сайту python.org](https://www.python.org/downloads/).
     > ⚠️ **ВАЖЛИВО:** Під час інсталяції обов'язково поставте галочку **"Add python.exe to PATH"** на першому екрані інсталятора!
   - **Спосіб Б (Через консоль):** Виконайте команду в PowerShell/cmd:
     ```powershell
     winget install Python.Python.3.11
     ```

#### Крок 2. Завантаження вихідного коду програми

- **Варіант 1 (Git):**
  ```bash
  git clone https://github.com/KozlitinI/PIIUA.git
  cd PIIUA
  ```
- **Варіант 2 (Завантаження ZIP):**
  На сторінці репозиторію GitHub натисніть **Code ➔ Download ZIP**, розпакуйте архів у зручну папку (наприклад, `C:\Work\PIIUA`).

#### Крок 3. Автоматичне встановлення компонентів

У папці програми двічі клацніть файл:
```text
install.bat
```
Скрипт автоматично:
1. Перевірить наявність Python у системі.
2. Створить віртуальне середовище `venv`.
3. Завантажить та встановить усі необхідні бібліотеки та мовні моделі spaCy (`uk_core_news_trf`, `uk_core_news_lg`, `uk_core_news_sm`).

#### Крок 4. Запуск програми

Після завершення встановлення запустіть програму двома кліками по файлу:
```text
run_app.bat
```
Сервер запуститься, і у вашому браузері автоматично відкриється веб-інтерфейс за адресою:
👉 **`http://127.0.0.1:8000`**

## 💻 Ручне встановлення (для Linux / macOS / Розробників)

Якщо ви використовуєте Linux, macOS або бажаєте встановити сервіс вручну:

1. **Клонуйте репозиторій та перейдіть у каталог проекту:**
   ```bash
   git clone https://github.com/KozlitinI/PIIUA.git
   cd PIIUA
   ```

2. **Створіть та активуйте віртуальне середовище:**
   - **Linux / macOS:**
     ```bash
     python3 -m venv venv
     source venv/bin/activate
     ```
   - **Windows (cmd/PowerShell):**
     ```cmd
     python -m venv venv
     venv\Scripts\activate
     ```

3. **Встановіть залежності та мовні моделі:**
   ```bash
   pip install --upgrade pip setuptools wheel
   pip install -r requirements.txt
   ```

4. **Запустіть сервер розробки:**
   ```bash
   python run_server.py
   ```
   або через `uvicorn`:
   ```bash
   uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
   ```
